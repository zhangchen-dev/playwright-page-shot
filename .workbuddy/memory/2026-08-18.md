## 修复：右下角「场景故事」文案丢失 + 地图预览需展示

- 现象：录制时填了「右下角场景故事主标/副标」，但最终导出的 `demo_config.json` 里 `introduction` 为空（所有真实场景 `introduction` 均为 null，证明系统性丢失）；地图预览右下角介绍文案也不展示。
- 根因（导出丢失）：`webview-recording.js` 在标记元素/捕获步骤时调用 `rerenderPanel()`，重建整个配置面板（`renderConfigPhase` 开头 `contentEl.innerHTML=''`）。`introBox` 按 `currentSubMod.introduction`（此时尚未保存、为 null）折叠、输入框被清空；保存时旧 `collectIntroduction()` 因 `introBox.style.display==='none'` 直接返回 null → 文案永久丢失。
  - ⚠️ 注意：`recorder.getState()` 对 `mainModules` 做**深拷贝**，`appState.state.mainModules` 与 `recorder.mainModules` 不是同一引用，故 oninput 直接改 state 不会进导出——必须用 `appState.savedInputValues`（跨重渲染保留输入的专用字段）做草稿。
- 修复（`renderer/modules/recording/shared/recording-ui.js`）：
  1. intro 输入框初值改为从 `savedInputValues['intro_'+主步骤_子步骤]` 草稿回填（优先级高于 `currentSubMod.introduction`）。
  2. 给两个 intro 输入加 `oninput` → 实时写入草稿；都空则删除草稿。
  3. `collectIntroduction()` 去掉 `display==='none'` 守卫，直接读输入框（折叠不丢值）。
  - 保存链路不变：collectIntroduction → 保存动作 `introduction` → recorder.subMod.introduction → 导出 `_buildConfig` 写 `introduction` + `recording_data.json`。
- 地图预览展示（`src/map-preview.js` + `src/map-template/app.js`）：
  1. `transformRecordingToMockConfig` 输出新增 `sceneStoryShow: true`（当任意步骤有非空 introduction）。
  2. `app.js` `transformData` 返回加 `sceneStoryShow`；`init()` 经 `Object.assign(AppState, config)` 应用，使有文案的场景自动显示右下角「场景故事」浮框。
  3. `updateSceneStory()` 增加守卫：当前步骤无故事文案时不弹空框。
  - 验证：`transformRecordingToMockConfig` 数据路径 PASS（introduction 透传 + sceneStoryShow=true）。浏览器渲染逻辑（step.introduction → #tipsTextQs/#tipsTextAs）已读代码确认。
- 说明：导出 `demo_config.json` 原逻辑本就读取 `subMod.introduction`，此前只是因 UI 没把文案送进来而写空；本次修复从源头补全。
