# 2026-08-20

## 相对→绝对地址补全的 base 基准 bug（playwright-page-shot）
- 根因：`src/html-capture.js` 在 DOM 清理时直接 `remove()` `<base>`，相对资源统一用 `currentUrl`（页面物理 URL）当 base；站点用 `<base href>` 声明逻辑根时拼错（如 CMB 站点 `.../app-home` 被错拼成 `.../app-home/assets/mhtml`）。
- 正确 base：浏览器 `document.baseURI`（有 base 用 base，无则页面 URL）；零成本、零额外请求，不影响录制。
- 方案（用户要求先只分析、未改代码）：`captureStep`/`processFromCapturedData` 在 evaluate 里返回 `document.baseURI`，`_fixResourceUrls`/`fixCssUrls`/iframe 处理统一用 `baseURI || currentUrl`；webview 路径需在 `captureWebviewData` 也带上 baseURI。
- 边界：存储路径≠逻辑路径且无 base 时只能靠 `envBaseUrl`/`originName` 兜底。

## 已落地修改（同 bug）
- `src/html-capture.js`：`captureStep` 的 evaluate 现返回 `{html, baseURI}`（`document.baseURI`）；新增 `docBaseUrl = capturedBase || currentUrl`；`new URL(href)`/inline `<style>`/`_fixResourceUrls`/`_captureIframes` 均改用 `docBaseUrl`；`_captureIframes` 额外 `matchedFrame.evaluate(() => document.baseURI)` 取 iframe 自身基准；`processFromCapturedData` 接收 `baseUrl` 参数并同样用 `docBaseUrl`，iframe 资源基准优先 `matched.baseURI`；两处加载后 `$('base').remove()` 防御。
- `renderer/modules/recording/internal/webview-recording.js`：`cleanupCode` 返回 `{html, baseURI}` JSON，iframe 捕获附带 `doc.baseURI`；`captureWebviewData` 回传 `baseURI`。
- `src/recorder.js`：`_nextStepWebview` 解构 `baseURI` 并作为 `baseUrl` 传入 `processFromCapturedData`。
- 验证：三个文件 `node --check` 通过；CMB 示例 `./index/.../icon4.svg` 新逻辑解析为 `.../app-home/index/...`（与期望一致），旧逻辑 `.../assets/mhtml/index/...` 错误。

## Playwright 依赖架构（分析：能否移除该包）
- 内部(webview)录制：`renderer/.../webview-recording.js` 的 `captureWebviewData` 用 `webview.executeJavaScript`（纯 Electron webview），不依赖 Playwright。
- 内部(webview)回放预览：`renderer/.../preview/preview.js` 的 `openPreview` 用 `webview.src = fileUrl`（Electron `#previewWebview`），不依赖 Playwright。
- 真正依赖 Playwright 的：`src/browser-manager.js`（外部录制 + `openLocalHtmlFile` 外部预览通道），由 `main/main.js:7,221,247` 在 GUI 启动期**无条件** `require + new BrowserManager()`，顶层 `require('playwright')`。
- 构建期硬依赖：`electron-builder.config.cjs:10` `require('playwright')` + `extraResources` 把 Playwright Chromium 打进安装包（~150MB+）；内部模式用不到（webview 用 Electron 自带 Chromium）。
- 结论：内部模式运行时无需 Playwright，但删包前必须改启动链（main.js/browser-manager.js/recorder-ipc.js/webview-ipc.js）+ 构建配置，否则 GUI 启动即崩。建议做成"可开关/可降级"而非物理删除。
