## 录制面板 2.6 修正「未开移动端却整页套手机壳」（2.5 的"非 bug"结论推翻）
- **用户再次报障**：明确"录制时没选移动端，地图预览全是移动端"。重新核查确认**这是确凿 bug**，2.5 的"非 bug"结论有误。
- **根因**：`map-preview.js` 的 `transformRecordingToMockConfig` 用 `detectMobileFromContent(html)`（viewport meta 启发式）**覆盖**了用户的显式 PC 意图——本场景 `isMobileMode=false`、`introduction.isMobileGuide=null/false`，但 step2-4 的 HTML 自带 `user-scalable=no / maximum-scale=1 / viewport-fit=cover` 这类移动 viewport（来自**响应式 PC 站点自身**，recorder 不注入、webview 仍是 PC 态）。旧逻辑 `subStepIsMobile = contentMobile!==null ? contentMobile : fallback` 把这些 PC 录制步骤**错误升级**成手机壳。
- **v16 启发式的本意**只是"降级"（用户开了移动端、但某步内容确为 PC 时回退全屏），不应用于"升级"。
- **修复（仅改 `map-preview.js`，不动 recorder 数据逻辑 / 导出）**：引入 `explicitMobile = subHasOwnFlag ? isMobileGuide : isMobileMode`；仅当 `explicitMobile` 为真且内容确证为 PC（`contentMobile===false`）时降级为 PC，其余保持移动端；**显式 PC 意图（未开移动端开关）一律不升级，恒为 PC**。
- **缓存失效**：`MAP_PREVIEW_VERSION` 由 `'21'` → `'22'`（generator 检测到旧 v21 缓存标记即清掉重建）；并手动删除测试场景旧缓存 `C:/Users/123/AppData/Local/Temp/map-preview-sen_code_GkrO3y/`。
- **验证**：`node --check` 通过；模拟 `transformRecordingToMockConfig(recData, false)` 对 `sen_code_GkrO3y` 实测 4 步 `selector.isMobileGuide` 全为 `false`（PC）。
- **结论 / 给用户的解释**：是否移动端以"录制时是否开移动端开关"为准；被录制页面自带的移动 viewport meta 不再影响预览壳子展示。

## 回归修复：上一版 `recording-actions.js` 把 const 写在对象字面量内 → 录制模块加载失败
- **致命语法错误**：对象字面量 `{ ... }` 内部**只能放键值对 / 展开 `...obj` / 计算属性 / shorthand / getter-setter**，**不能放语句**（包括 `const`/`let`/`var` 声明、`if`/`for`/表达式语句等）。对象字面量本质是「零或多条 property_definition」，不是语句块。
- **症状**：上一版我在 `sendAction('endAndSave', { ...reRecordSaveMode: ..., const x = ..., isMobile: x })` 里直接把 `const _mobileSwitchCb = ...` 塞进对象内，整个模块解析失败（`SyntaxError`），录制模块无法被 ESM 加载 → 用户"现在没法正确录制"。
- **修复**：把 `const` 声明移到对象字面量**外侧**（`sendAction(...)` 之前），对象内只留 `isMobile: _mobileSwitchChecked`（引用外侧已算好的变量）。这是合法且惯用的写法。
- **教训**：以后改 renderer 模块，每次务必用 `node --input-type=module --check < path/to/file.js` 做严格 ESM 语法校验，不能只看缩进就提交；任何报错（exit≠0）都不能放过。`Function(src)` 粗校验不能抓出所有错误（顶层 `const` 会误报，但对对象字面量内的 `const` 抓不出 → 漏掉了这次回归）。
- **当前校验**：node --input-type=module --check exit=0，ACORN 不可用（未装）但 node 内置解析已通过。
