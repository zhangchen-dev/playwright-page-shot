## 内部浏览器加载失败 → 弹 modal.error 告知用户
- 诉求：内部浏览器（`<webview>`）打开地址失败时，后台有 `ERR_NAME_NOT_RESOLVED (-105)` 等错误，但应用内无提示，用户不知情。要求以 modal.error 形式弹窗。
- `renderer/modules/common/feedback.js` 新增两个工具：
  - `showErrorModal(title, message, { code, url, confirmText, onClose })`：红色标题错误弹窗，仅「知道了」按钮（点击/Esc/点遮罩关闭），展示错误描述、错误码、失败地址。
  - `notifyWebviewLoadFail(e)`：封装「主框架失败才弹 + 去重」。仅 `e.isMainFrame === true`（主框架）才提示；子资源（iframe/图片/xhr）失败 `isMainFrame=false` 不弹，避免刷屏；同地址 1.5s 内只弹一次（防导航重试连弹）。
- 接入位置（仅交互层，未动底层）：
  - `webview-controls.js`（主预览/录制 webview `previewWebview`）：`did-fail-load` 合并为 `hideLoading() + notifyWebviewLoadFail(e)`；新增 `did-fail-provisional-load` 兜 DNS 类早期失败。
  - `tabs.js`（target=_blank 弹窗 webview）：`did-fail-load` 里调 `notifyWebviewLoadFail(e)`。
- 校验：`node --input-type=module --check` 三文件均通过。
- 生效：renderer 改动需重启 Electron / 重打包。
